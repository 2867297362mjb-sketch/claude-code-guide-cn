② 解析本地会话文件

文件只在你的浏览器里读取和计算，不会上传。页面的内容安全策略（CSP）只允许向本站发请求，加载完后断网也能用。

Claude Code 把每个会话记成一个 .jsonl 文件，放在：

  • macOS / Linux：~/.claude/projects/
  • Windows：C:\Users\<用户名>\.claude\projects\

.claude 是隐藏目录。macOS 选择文件时按 ⌘⇧. 显示隐藏文件，或按 ⌘⇧G 粘贴路径；Windows 直接把路径粘贴到对话框地址栏。选「整个文件夹」会连子代理的记录一起统计。

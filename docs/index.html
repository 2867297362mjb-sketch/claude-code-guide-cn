一句话答案

装好 Node.js 22+ 和 Claude Code，把 ANTHROPIC_BASE_URL 指向一个支持 Anthropic 原生协议的 API 平台，Key 填进 ANTHROPIC_AUTH_TOKEN，就能用。真正决定体验和账单的是另外两件事：钉住模型 ID，别让缓存断掉。

npm i -g @anthropic-ai/claude-code                      # 需要 Node.js 22+
export ANTHROPIC_BASE_URL=https://api.teamorouter.com   # 换成你的平台地址，不要带 /v1
export ANTHROPIC_AUTH_TOKEN=你的Key
export ANTHROPIC_MODEL=claude-opus-5-5
claude

上面只在当前终端生效。永久生效、Windows 和 settings.json 写法见下一节，或直接用 配置生成器。

5 分钟配置

  1. 安装 Claude Code 装 Node.js 22 或更新版本（Windows 另装 Git for Windows），然后： 
    npm i -g @anthropic-ai/claude-code
# npm 慢的话临时用国内镜像
npm i -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
    claude --version 确认版本。Sonnet 5.5 需要 2.1.284 以上，旧版本先 claude update。
  2. 写配置（推荐 settings.json，三平台通用） 文件在 ~/.claude/settings.json（Windows：C:\Users\<用户名>\.claude\settings.json）。已有文件时只合并 env 里这几项，不要整个覆盖。 
    {
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.teamorouter.com",
    "ANTHROPIC_AUTH_TOKEN": "你的Key",
    "ANTHROPIC_MODEL": "claude-opus-5-5",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-5-5",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-5-5",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-4-5"
  }
}
    想用 shell 环境变量或 Windows setx，用 配置生成器 选系统，一键生成可复制的配置。
  3. 验证 新开终端运行 claude：不再要求登录 Anthropic 账号，说明 Key 已被读到；输入 /status 看 base URL 是不是你填的地址，/model 看 opus / sonnet / haiku 是否指向钉住的 ID。

三个最常见的坑

  • ANTHROPIC_BASE_URL 不带 /v1，Claude Code 会自己拼 /v1/messages，多写了会 404。
  • ANTHROPIC_AUTH_TOKEN 和 ANTHROPIC_API_KEY 只留一个，推荐前者；机器上留着旧的 ANTHROPIC_API_KEY 容易「填了新 Key 用的却是旧 Key」。
  • 模型 ID 用短横线：claude-opus-5-5，不是 claude-opus-5.5。

同一个变量既在系统 / 终端环境变量里、又在 settings.json 的 env 里时，环境变量优先（Claude Code 2.1.284 实测）。改了 settings.json 不生效，多半是 ~/.zshrc 或 Windows 用户环境变量里还留着旧值。

钉住模型别名

Claude Code 里的 opus、sonnet、haiku 是别名。不钉住时，它按自己版本内置的默认 ID 去请求；平台没有这个 ID 就报 400 / 404，或者落到旧模型上。

变量作用建议值
ANTHROPIC_MODEL启动时默认用的模型claude-opus-5-5
ANTHROPIC_DEFAULT_OPUS_MODEL/model 里 opus 指向的 IDclaude-opus-5-5
ANTHROPIC_DEFAULT_SONNET_MODELsonnet 指向的 IDclaude-sonnet-5-5
ANTHROPIC_DEFAULT_HAIKU_MODELhaiku 指向的 ID，用于会话标题、摘要等后台小任务，最容易被忽略claude-haiku-4-5
CLAUDE_CODE_SUBAGENT_MODEL子代理用的模型claude-sonnet-5-5

官方价：Opus 5.5 输入 / 输出 $4 / $20、缓存读 $0.20；Sonnet 5.5 输入 / 输出 $2 / $10（美元 / 每百万 token）。其他模型和最新价格见 账单计算器，价格数据每日同步，以官网价格页为准。不同平台的 ID 可能有差异，以平台模型列表为准。

数据来源：TeamoRouter 平台 2026 年 10 月 7 日至 13 日，Claude Code 客户端调用 Opus 5.5 的约 20.6 万次成功请求（399 位用户）。金额按 Anthropic 官方价折算，与任何平台的实际售价无关。

Claude Code 每一轮都会把系统提示、CLAUDE.md、工具定义和历史对话整段重发。这 24 万 token 如果全按 Opus 5.5 输入价 $4 / 百万计，光输入就是 $0.96，是实际平均每次 $0.179 的五倍多。缓存命中率决定账单。

  1. 会话中途别改 CLAUDE.md，别增删 MCP 工具。重发内容的开头一变，下一轮整段都按全价算。
  2. 一个会话只用一个模型。缓存按模型分开，/model 来回切，每次切完的第一轮都是全价。
  3. haiku 别名钉一个便宜的小模型，不设的话后台小任务会请求平台可能没有的 ID。
  4. 子代理用 Sonnet 5.5，主线程用 Opus 5.5。CLAUDE_CODE_SUBAGENT_MODEL=claude-sonnet-5-5，单价只有 Opus 5.5 的一半。
  5. 思考档按任务调，不要常驻最高档。思考 token 按输出价计费，小活用 low / medium。
  6. 及时 /compact，做完就 /clear 或开新会话。上下文越长，每轮重发越多。
  7. 长时间、多轮的编码任务放在走 Anthropic 原生协议的工具里做。OpenAI 兼容协议接入通常吃不到缓存。

两个小工具

Claude Code 账单计算器

按请求数、上下文和缓存命中率估算每月花费；或选择本机 ~/.claude/projects/ 下的会话文件，在浏览器本地解析真实用量，不上传。

Claude Code 配置生成器

选系统、填 Base URL 和模型，生成 shell / PowerShell / settings.json 配置。Key 只在本地拼进文本，不发送、不保存。

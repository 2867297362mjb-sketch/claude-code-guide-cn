Claude 客户端 Cowork 接第三方 API

Claude 客户端（Claude Desktop）自带第三方推理设置，Cowork 和 Code 都能直接用 Anthropic 兼容平台的地址和 Key，不需要 Claude 订阅。下面是在客户端里直接配置的步骤，字段名按客户端 2.31226.0 版本核对。

配置步骤

  1. 打开开发者模式：菜单栏 Help → Troubleshooting → Enable Developer Mode。客户端可能会重启，之后菜单栏出现 Developer。Windows 在登录界面左上角的 ☰ 菜单里。
  2. 选择 Developer → Configure Third-Party Inference…，打开配置窗口。
  3. 按下表填写：
    字段填写
    Inference providerGateway
    Gateway base URL平台给的 Anthropic 兼容地址，只写到域名，不带 /v1
    Credential kindStatic API key
    Gateway API key平台的 Key
    Gateway auth schemeBearer（默认）。平台只认 x-api-key 请求头时改成 x-api-key
    Models平台支持 /v1/models 时会自动列出；列表为空就手动添加模型 ID
  4. 保存配置。客户端没有自动重启的话，完全退出再打开。
需要一个国内能直接连的 Anthropic 兼容地址：TeamoRouter，按量计费 看 TeamoRouter 的 Claude 客户端接入文档

利益相关：本页由 TeamoRouter 团队维护，TeamoRouter 不是 Anthropic 官方渠道。上面的步骤对任何 Anthropic 兼容平台通用。

常见问题

菜单里没有 Developer 或 Configure Third-Party Inference

先在 Help → Troubleshooting 打开 Enable Developer Mode。打开后仍然没有，说明客户端版本太旧，到 claude.ai/download 下载最新版。

Windows 提示 Virtual Machine Platform not available

Cowork 的工作区需要 Windows 的「虚拟机平台」：Win + R 输入 optionalfeatures，勾选「虚拟机平台」（Virtual Machine Platform），确定后重启电脑。

连接失败或 401

多半是地址多写了 /v1、Key 复制不全，或者 auth scheme 和平台要求不一致（Bearer 和 x-api-key 填反）。可以先用 curl 直接请求一次排除客户端问题，方法见 Invalid API key 排查。

模型列表是空的

平台没有提供 /v1/models，或者返回的 ID 和你想用的不一样。在 Models 里用 Add model 手动添加模型 ID，例如 claude-opus-5-5、claude-sonnet-5-5。

改了配置不生效

大部分设置要重启才生效。完全退出客户端（macOS 用 Cmd+Q，Windows 从托盘退出）再打开。

想切回官方订阅

在 Configure Third-Party Inference 里清掉配置并保存，或者关掉开发者模式：Developer → Open Developer Config File，把 "allowDevTools": true 改成 false，保存后重启。

账单比预期高

Cowork 每一轮都会带上工具定义、系统提示和之前的对话，平台必须保留 cache_control 才能命中缓存。可以用 账单计算器 看会话的缓存命中率。

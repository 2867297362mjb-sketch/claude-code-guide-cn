Claude Code 配置生成器

选系统、填地址和模型，生成可以直接粘贴的配置。适用于任何支持 Anthropic 原生协议的平台。

Key 只在你的浏览器里拼进下面的文本：不发送到任何地方、不进网址、不存进浏览器存储，刷新页面就清空。本页的内容安全策略（CSP）禁止发起任何网络请求。

写法
你的 shell（终端里 echo $SHELL 查看）
任何 Anthropic 兼容地址都可以。只写到域名，不要带 /v1，Claude Code 会自己拼 /v1/messages。
只用 ANTHROPIC_AUTH_TOKEN（发 Authorization: Bearer），生成的配置会去掉 ANTHROPIC_API_KEY，两个只留一个。
启动时默认用的模型。
会话标题、摘要等后台小任务用它，最容易被忽略。
搜代码、跑测试这类子任务交给它，Sonnet 5.5 单价是 Opus 5.5 的一半。
其他

模型输入框留空表示不设置这一项。不同平台的模型 ID 可能不同，以平台模型列表为准。

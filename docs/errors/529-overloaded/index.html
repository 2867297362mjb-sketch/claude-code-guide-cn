Claude Code 报错 API Error: 529 Overloaded 怎么办

模型服务端暂时过载，不是你的配置问题。等一会儿重试，或者先换一个模型。

报错原文

API Error: 529 Overloaded

新版本会接着提示：This is a server-side issue, usually temporary — try again in a moment. If it persists, check https://status.claude.com.

这条报错是什么意思

529（overloaded_error）表示上游当前容量不足，无法处理这次请求。Claude Code 会自动重试几次，重试也失败才把这条报错显示出来。

常见原因

  1. 官方在高峰期容量紧张，新模型刚发布那几天尤其常见。
  2. 用第三方平台时，平台把上游的 529 透传了过来，或者平台自己的线路容量不足。

怎么排查

  1. 等一两分钟再发。

  2. 急着用的话，用 /model 先切到另一个模型，比如从 Opus 切到 Sonnet。

  3. 打开 status.claude.com 看官方有没有故障公告。

  4. 用第三方平台时，如果官方状态正常、只有你这边一直 529，把报错时间和 request_id 发给平台客服。

相关报错

  • API Error: 429 rate_limit_error
  • There's an issue with the selected model
  • Unable to connect to Anthropic services

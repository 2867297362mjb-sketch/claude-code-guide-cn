Claude Code 报错 API Error: 429 rate_limit_error 怎么解决

请求太快或用量到了上限。官方 API 按账户等级限速，订阅按时间窗口限额，第三方平台按 Key 限速。等一会儿，或者降低并发。

报错原文

API Error: 429 {"type":"error","error":{"type":"rate_limit_error", ...}}

用订阅时，类似的情况会显示为用量已达上限、几点重置。

这条报错是什么意思

429 表示在一段时间内的请求数或 token 数超过了允许的上限，和 Key 对不对无关。

常见原因

  1. 官方 API 的账户等级较低，每分钟请求数或 token 数有上限。
  2. 订阅的用量窗口或每周额度用完了。
  3. 同时开了很多子代理或多个会话，瞬时并发太高。
  4. 第三方平台对单个 Key 有限速。

怎么排查

  1. 等几分钟再试。订阅用户看提示里的重置时间。

  2. 减少同时跑的会话和子代理数量。

  3. 长期不够用：官方 API 可以提升账户等级；订阅可以升级套餐，或者改用按量计费的 API。

  4. 用第三方平台时，问清楚平台对单个 Key 的限速是多少。

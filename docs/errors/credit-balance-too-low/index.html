Claude Code 报错 Credit balance is too low 怎么解决

Claude Code 在用官方 Console 的 API Key 计费，而这个账户的余额用完了。很多人其实想用订阅，却因为机器上设了 ANTHROPIC_API_KEY，被按 API 余额扣费。

报错原文

Credit balance is too low to access the Anthropic API. Please go to Plans & Billing to upgrade or purchase credits.

这条报错是什么意思

这条报错来自 Anthropic 官方 API，说明请求用的是 Console 里创建的 API Key，按 API 余额计费，和 Pro / Max 订阅额度无关。

常见原因

  1. 机器上设了 ANTHROPIC_API_KEY，Claude Code 优先用它，没走你的订阅。
  2. Console 账户的 API 余额确实用完了。

怎么排查

  1. 想用 Pro / Max 订阅：删掉 ANTHROPIC_API_KEY，在 Claude Code 里 /login 用订阅账号登录。

    unset ANTHROPIC_API_KEY

  2. 就是想用官方 API：到 Console 的 Plans & Billing 页面充值。

  3. 用第三方平台时不会出现这句原文。平台余额不足时一般返回 402 或平台自己的提示，充值后重试即可。

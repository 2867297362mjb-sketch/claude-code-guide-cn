Claude Code 报错 There's an issue with the selected model 怎么解决

当前选的模型 ID 请求失败了。先检查 ID 拼写和平台模型列表；如果都没问题，用 curl 直接请求一次，看真实的报错是什么。

报错原文

There's an issue with the selected model (claude-opus-5-5). It may not exist or you may not have access to it.

括号里是你当前选的模型 ID。

这条报错是什么意思

Claude Code 请求某个模型失败时会显示这条提示。它不一定真的表示模型不存在：上游的其他错误有时也会被显示成这句话，所以要看原始返回才能确定原因。

常见原因

  1. 模型 ID 写错了，比如写成了点号 claude-opus-5.5，正确的是短横线 claude-opus-5-5。
  2. 所用平台没有上架这个模型，或者你的 Key 没有这个模型的权限。
  3. Claude Code 版本太旧，不认识新模型。
  4. 上游的其他错误被显示成了这句话。

怎么排查

  1. 核对 ANTHROPIC_MODEL 和 ANTHROPIC_DEFAULT_OPUS_MODEL、ANTHROPIC_DEFAULT_SONNET_MODEL、ANTHROPIC_DEFAULT_HAIKU_MODEL 里的 ID，和平台模型列表逐字对照。

  2. 升级 Claude Code：

    claude update

  3. 直接请求一次，看平台返回的原始错误（把 model 换成你在用的 ID）：

    curl -sS "$ANTHROPIC_BASE_URL/v1/messages" \
  -H "Authorization: Bearer $ANTHROPIC_AUTH_TOKEN" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{"model":"claude-opus-5-5","max_tokens":16,"messages":[{"role":"user","content":"hi"}]}'

curl 命令里用的是 Claude Code 的同名环境变量，在设好变量的终端里直接运行即可，Key 不会显示出来。Windows 用户可以在 Git Bash 或 WSL 里运行。

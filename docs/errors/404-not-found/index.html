Claude Code 配置第三方 API 后报 404 怎么解决

多半是 ANTHROPIC_BASE_URL 多写了 /v1。Claude Code 会自己在地址后面拼 /v1/messages，地址只写到域名即可。

报错原文

API Error: 404

这条报错是什么意思

404 表示请求的路径在服务端不存在。地址写成 https://平台域名/v1 时，实际请求会变成 /v1/v1/messages。

常见原因

  1. ANTHROPIC_BASE_URL 末尾多了 /v1 或其他路径。
  2. 平台不支持 Anthropic 原生协议，只提供 OpenAI 兼容接口（/v1/chat/completions）。Claude Code 只能接 Anthropic 原生协议。

怎么排查

  1. 把地址改成只到域名（以平台文档为准）：

    export ANTHROPIC_BASE_URL=https://api.example.com   # 不要带 /v1

  2. 确认平台提供 Anthropic 原生协议的 /v1/messages 接口。只有 OpenAI 兼容接口的平台不能直接给 Claude Code 用。

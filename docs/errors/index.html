Claude Code 报错速查

把终端里的报错和下面的原文对一下，点进去看原因和排查步骤。内容对任何支持 Anthropic 原生协议的平台通用。

  • Unable to connect to Anthropic services

    Claude Code 连不上 api.anthropic.com。国内最常见的原因是直连官方不通，或者设置的第三方地址没有被 Claude Code 读到，它还在连官方。

  • API Error: 403 Request not allowed

    请求被服务端直接拒绝了。用官方账号时，多半是网络出口地区或账号状态的问题；用第三方平台时，多半是 Key 没有这个模型的权限。

  • Invalid API key · Please run /login

    发出去的 Key 不对。最常见的原因是机器上同时留着 ANTHROPIC_API_KEY 和 ANTHROPIC_AUTH_TOKEN，Claude Code 用了你没想到的那一个。

  • API Error: 529 Overloaded

    模型服务端暂时过载，不是你的配置问题。等一会儿重试，或者先换一个模型。

  • Credit balance is too low

    Claude Code 在用官方 Console 的 API Key 计费，而这个账户的余额用完了。很多人其实想用订阅，却因为机器上设了 ANTHROPIC_API_KEY，被按 API 余额扣费。

  • API Error: 400 Invalid signature in thinking block

    会话历史里的思考块对不上当前的服务端。最常见的原因是在同一个会话里换了平台或模型。新开一个会话就能恢复。

  • There's an issue with the selected model

    当前选的模型 ID 请求失败了。先检查 ID 拼写和平台模型列表；如果都没问题，用 curl 直接请求一次，看真实的报错是什么。

  • API Error: 429 rate_limit_error

    请求太快或用量到了上限。官方 API 按账户等级限速，订阅按时间窗口限额，第三方平台按 Key 限速。等一会儿，或者降低并发。

  • API Error: 404

    多半是 ANTHROPIC_BASE_URL 多写了 /v1。Claude Code 会自己在地址后面拼 /v1/messages，地址只写到域名即可。

没找到你的报错？到 GitHub Issues 贴出报错原文（记得删掉 Key）。
